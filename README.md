# book_web_store

BookWeb — Sample Instructions

1. Keep all folders and files together inside one main folder named "bookweb".

2. "index.html" is the main page. Open/click "index.html" to launch the website.

3. If the images are not loading in "index.html", change the image path to use only the image filename.

4. Make sure the required image filename is "test_book_1.jpng".

5. This is only a sample/test version, not the final product.
